# Android 配置文档

本文档只记录本项目 Android 端运行所需的最少配置。

## 1. 打开项目

用 Android Studio 打开：

```bash
frontend/android
```

不要打开项目根目录，也不要只打开 `frontend`。

## 2. 启动后端

在项目根目录执行：

```bash
cd backend
source venv/bin/activate
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

确认接口可访问：

```text
http://10.0.2.2:8000/health
```

模拟器里看到 `{"status":"healthy"}` 即表示后端连通。

## 3. 构建 Android 前端资源

在项目根目录执行：

```bash
cd frontend
$env:VITE_API_BASE_URL="http://10.0.2.2:8000"
npm run build
npx cap sync android
```

然后回到 Android Studio，选择模拟器，点击绿色 Run。

## 4. 关键配置

模拟器访问电脑本机后端时使用：

```text
http://10.0.2.2:8000
```

真机调试时不能使用 `10.0.2.2`，需要改成电脑的局域网 IP，例如：

```text
http://192.168.x.x:8000
```

Android 本地页面使用 HTTP 协议，避免 HTTPS 页面请求 HTTP 后端时被 Mixed Content 拦截。
